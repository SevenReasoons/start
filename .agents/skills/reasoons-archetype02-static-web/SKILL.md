# 📄 Skill: Arquetipo 02 — Página Web Estática (SSG)

> **Familia 1:** Captación & Presencia  
> **Propósito:** Portafolios, blogs técnicos y sitios institucionales con máxima calificación en Google Lighthouse (100/100).

---

## ⚡ Especificación Técnica
- **Stack:** Next.js App Router con Static Site Generation (`output: 'export'` o ISR en Edge).
- **Rendimiento:** `<Image>` optimizado en WebP/AVIF, fuentes autohospedadas con `next/font/google`.
- **SEO & i18n:** Rutas organizadas bajo `app/[locale]/...` con etiquetas canónicas y `hreflang` bilingüe (ES/EN).
