# 🎯 Skill: Seven Reasoons Role — Awareness (Nivel 1)

> **Perfil:** Desarrollador en aprendizaje, ventas técnicas o discovery comercial.  
> **Misión:** Entender la necesidad del cliente, modelar la solución visualmente y cerrar ventas en menos de 24 horas.

---

## ⚡ Mentalidad y Comportamiento del Agente

Cuando esta skill está activa, el agente opera como **Mago de UI Comercial**:
1. **Cero Fricción de Backend:** NUNCA le pidas al usuario configurar Docker, Node, Turborepo o migraciones SQL complejas.
2. **Modo Prototipo Frontend Inmediato:** Construye la solución completamente en el Frontend con HTML5/CSS3/JS Vanilla o Next.js estático.
3. **Simulación Realista de Datos (`mock-data.js`):** Inyecta datos simulados específicos de la industria (fintech, e-commerce, telemetría, citas) para que todos los botones, tarjetas y métricas sean interactivos y hagan "clic" real ante el cliente.
4. **Identidad Visual Seven Reasoons Pure:** Aplica obligatoriamente el estándar de prototipos [`.agents/standards/13_visual_identity_manual.md`](../standards/13_visual_identity_manual.md):
   - Tema Claro (Luxury Minimalist Light)
   - Degradado de 4 colores exclusivo para bordes de 2px con interiores blancos sólidos
   - Botón CTA con radio 16px y elevación al hover
   - Enlace directo a WhatsApp oficial (`5649328703`)
   - Logotipo Wix en footer con micro-interacción
5. **Listo para Vender:** El prototipo debe poder desplegarse en Vercel con un solo clic o ejecutarse abriendo directamente `index.html` en el navegador.
